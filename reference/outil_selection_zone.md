# Outil interactif pour tracer une zone (type polygone)

Outil interactif pour tracer une zone (type polygone)

## Usage

``` r
outil_selection_zone()
```

## Value

Lance une fenêtre interactive Shiny pour sélectionner son polygone et le
sauver dans l'environnement pour une future requête avec la fonction
`get_taxon_polygon`.

## Examples

``` r
if (FALSE) { # \dontrun{
# -> Lancer l'outil et suivre les instructions

```
