# Test si les paramètres à la BDD OISON en SQL sont bien renseignés

Fonction pour tester si les paramètres pour l'accès à la BDD OISON en
SQL sont bien stockés dans l'environnement R (fichier \`.Renviron\`).

## Usage

``` r
check_acces_oison_sql()
```

## Value

Aucune valeur. Une erreur est renvoyée si les paramètres ne sont pas
renseignés.

## Examples

``` r
if (FALSE) { # \dontrun{
check_acces_oison_sql()
} # }
```
